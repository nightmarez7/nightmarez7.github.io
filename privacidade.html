Política de Privacidade: Zona Curiosa Studio

Última atualização: 17 de novembro de 2026.

O que é

O Zona Curiosa Studio é uma ferramenta pessoal que gerencia canais do YouTube de quem a autoriza. Ela roda em um computador pessoal e não é vendida nem oferecida ao público.

Quais dados acessa

Com a sua autorização pelo login do Google, a ferramenta acessa pela API do YouTube apenas o seu canal: informações do canal, seus vídeos (para enviar e editar), comentários dos seus vídeos e, quando autorizado, as estatísticas do canal (YouTube Analytics). Ela não acessa e-mail, contatos, arquivos ou qualquer outro dado da sua conta Google.

Como usa

Os dados são usados só para gerenciar o seu canal: enviar vídeos, ajustar títulos e descrições, rascunhar respostas a comentários e montar relatórios de desempenho. Nada é publicado sem aprovação do dono do canal.

Onde fica guardado

O token de acesso e os relatórios ficam guardados só no computador onde a ferramenta roda, protegidos por senha do sistema. Os dados não são vendidos, compartilhados com terceiros nem usados para publicidade.

Uso de dados do Google

O uso de informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado. A ferramenta usa os Serviços de API do YouTube; ao usá-la, você também concorda com os Termos de Serviço do YouTube e com a Política de Privacidade do Google.

Como remover o acesso

Você pode cancelar o acesso a qualquer momento em myaccount.google.com/permissions. Depois disso, o token guardado deixa de funcionar e pode ser apagado a pedido.
